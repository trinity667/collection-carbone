Chargement des logiciels…
En quatre étapes

Installer une version d’essai

Nos versions d’essai fonctionnent sur Windows 10 et 11 (64 bits), sans installation compliquée.

Téléchargez

Cliquez sur « Télécharger » sous le logiciel à tester. Le fichier arrive dans votre dossier Téléchargements.

Extrayez

Clic droit sur le fichier .zip, puis « Extraire tout… ». Choisissez un dossier, par exemple Documents.

Lancez

Ouvrez le dossier extrait et double-cliquez sur le programme .exe du logiciel.

Autorisez

Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires », puis « Exécuter quand même ».
