Connexion

Le tableau de bord publie les logiciels à tester sur votre dépôt GitHub . Collez votre jeton d’accès GitHub : il reste dans ce navigateur, rien n’est envoyé ailleurs qu’à GitHub.

Comment obtenir un jeton ?

Logiciels à tester

Ouvert : téléchargeable. Fermé : visible, sans téléchargement. Masqué : absent du site.

Ajouter un logiciel

Guide : publier un logiciel à tester

1. Créer votre jeton GitHub (une seule fois)

  1. Ouvrez github.com › Settings › Fine-grained tokens › Generate new token.
  2. Nom : « Tableau de bord Collection Carbone ». Expiration : 90 jours (à renouveler ensuite).
  3. Repository access : « Only select repositories », puis choisissez .
  4. Permissions › Repository permissions › Contents : « Read and write ». Rien d’autre.
  5. « Generate token », copiez-le et collez-le dans « Connexion » ci-dessus. Ne le partagez jamais.

2. Préparer une version d’essai (accès limité)

  1. Le testeur ne doit voir que certaines parties : construisez une édition d’essai. Pour Carbone Espaces :
    scripts\build-espaces.ps1 -Version 0.8.0 -Essai "photo,graphisme,motion,montage,son,3d"
  2. Parties possibles : photo, graphisme, motion, montage, son, 3d, donnees. Seules celles listées apparaissent ; Lots, le pilote du jour et les mises à jour sont retirés.
  3. Le fichier prêt à publier est dans dist\Carbone-Espaces-Essai-<version>-windows-x64.zip.
  4. Pour un autre logiciel : préparez de même une version qui n’ouvre que les parties à tester, en un seul .zip ou .exe.

3. Le publier ici

  1. « ＋ Ajouter un logiciel », remplissez la fiche, choisissez le fichier, puis « Publier ».
  2. Le fichier part dans une « Release » GitHub (jusqu’à 2 Go), la fiche dans la liste du site.
  3. Le site se met à jour tout seul en une à deux minutes.
  4. Si le navigateur ne peut pas envoyer un gros fichier, la page de la Release s’ouvre : glissez-y le fichier, puis « Update release ». Le lien du site est déjà le bon.

4. Ce que voit le testeur

  1. Sur le site, il voit la fiche, les parties ouvertes, les étapes d’installation et le bouton « Télécharger l’essai ».
  2. Dans le logiciel, seules les parties de l’essai sont présentes, avec le badge « Version d’essai · Collection Carbone ».
  3. Il n’a jamais accès à ce tableau de bord : sans votre jeton, cette page ne peut rien modifier.
